HOW TO FLASH DIRECTLY FROM ANDROID MOBILE
A
Method 1 (Easiest - Chrome Browser):
Connect ESP32-C3 to your Android phone with a USB-C to USB-C cable. Open this page in Google Chrome on Android, tap "Connect & Install Firmware", grant USB permission when prompted, and let it flash!
B
Method 2 (Using Android App like Serial USB Terminal or ESP32 Loader):
1. Download spearhead_merged_factory_4mb.bin to your phone's Downloads folder.
2. Connect ESP32-C3 via OTG cable.
3. In the flasher app, select baud rate 460800 or 115200.
4. Choose file spearhead_merged_factory_4mb.bin at address 0x00000000.
5. Tap Flash / Program!
C
Method 3 (Desktop esptool.py command):
python -m esptool --chip esp32c3 --port COMx write_flash 0x0 assets/bins/spearhead_merged_factory_4mb.bin
